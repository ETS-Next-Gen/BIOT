# Py-BIOT
This implemenation converts R code from the master branch to a pythonic version using pytorch. All the functions are identical to the original implemenation in R. 

## How do I run BIOT?
The source code is available in the src folder. We have added enough explainations to the main.py iteself to follow the code easily. 

Here is how to run BIOT `python main.py`
